# 🎮 Puissance 4

## 📌 Description

Puissance 4 est un jeu de stratégie développé en Python, dans lequel deux joueurs s'affrontent sur une grille de 7 colonnes et 6 lignes. Le but est d'aligner 4 jetons de sa couleur horizontalement, verticalement ou en diagonale avant son adversaire.

## ✨ Fonctionnalités

- Jeu à deux joueurs.
- Gestion des tours de jeu.
- Vérification automatique des conditions de victoire.
- Détection des matchs nuls.
- Possibilité de recommencer une partie.

## 🛠️ Technologies utilisées

- Python 3

Ce projet a pour objectif de mettre en pratique les bases de la programmation Python, notamment les boucles, les conditions, les fonctions et la gestion des données, à travers la création d'un jeu interactif.
